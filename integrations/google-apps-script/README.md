# Заявки Редстар → Google Таблица

Текущий обработчик отправляет заявки только в таблицу «Заявки с сайта»:
https://docs.google.com/spreadsheets/d/1R_l94R9Qu84GR18RoVctYjZt0dSp9kTFhKioUBzFFV0/edit
Telegram, токен бота и свойства скрипта не требуются.

1. Замените весь код Apps Script содержимым Code.gs из этой папки и сохраните.
2. Выберите функцию setup и нажмите «Выполнить». Владелец разрешает доступ к таблице.
3. setup создаёт лист «Заявки сайта» с 16 столбцами. Существующие листы и данные не удаляет. Если такой лист уже содержит другую структуру, выполнение остановится; перед миграцией сохраните данные.
4. Разверните как веб-приложение: выполнять от имени владельца, доступ для всех посетителей. Передайте публичный URL с окончанием /exec разработчику.
5. Укажите URL в assets/leads-config.js и обновите версию его подключения на страницах.
6. После публикации проверьте реальную тестовую заявку в таблице. До этой проверки подключение не считается завершённым.

Колонки: ID заявки, дата по Москве, имя, телефон, задача, страница формы, название страницы, страница перехода, блок кнопки, текст кнопки, форма, два согласия и три UTM-параметра.

Повторная отправка с тем же ID не создаёт дубль. Значения, похожие на формулы, экранируются. Действуют проверка полей, поле-ловушка и лимит всплесков по телефону. Контекст перехода хранится 30 минут в sessionStorage без персональных данных. Успех показывается только после подтверждённого сохранения строки.

Не меняйте порядок технических колонок. Тесты с подменённой сетью: node tests/leads.test.cjs. Они не отправляют реальные заявки.
## Смена домена сайта

Скрипт принимает заявки только со страниц адресов, перечисленных в `valid_()`. После смены домена
вставьте обновлённый Code.gs в редактор Apps Script и выпустите новую версию того же развёртывания:
«Развёртывание» → «Управление развёртываниями» → карандаш → «Версия: новая» → «Развернуть».
Адрес с окончанием /exec при этом не меняется, правка `assets/leads-config.js` не нужна.
