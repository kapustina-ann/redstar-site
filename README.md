# Редстар — многостраничный сайт, вариант «Синий контур»

Черновик редизайна сайта агентства интернет-маркетинга «Редстар» (Ярославль).
Статический HTML без сборки и зависимостей: открывается прямым открытием `index.html`.

## Откуда взялось оформление

Построено на логобуке «Редстар» 2026:

| Роль | Значение |
|---|---|
| Основной тёмный | `#083575` |
| Акцент | `#0097EA` |
| Действие | `#D92C04` |
| Светлый | `#E4E4E4` |
| Монохром | `#1A1A1A` · `#595959` · `#8C8C8C` · `#FFFFFF` |

Шрифт по логобуку — **Gilroy**. Он лицензионный и в Google Fonts отсутствует,
поэтому в CSS стоит стек `'Gilroy', 'Montserrat', Arial`: подключите Gilroy
self-hosted, и он подхватится без правок разметки.

## Карточки журнала

Карточка одна на все случаи: блок с кадром необязателен. С картинкой и без
неё карточки стоят в одной ленте, в ряду выравниваются по высоте — дата
прижата к низу.

**Кадр** всегда 16:9, обрезается по центру, так что подбирать изображение
под вёрстку не нужно — подойдёт любое с этим соотношением. Рекомендуемый
файл — **1200×675** (колонка около 420 пикселей, запас на ретину).

```html
<a class="post-card" href="…" data-tags="seo">
  <div class="post-card__media"><img src="…" alt="…" width="1200" height="675"></div>
  <div class="post-card__body">
    <span class="tag">Рубрика</span>
    <h4>Заголовок</h4>
    <p class="post-meta">12 сентября 2026 · 7 мин</p>
  </div>
</a>
```

**Без картинки** — тот же код без блока `post-card__media`. Освободившееся
место занимает подводка `post-card__lead` на одно-два предложения:

```html
<a class="post-card" href="…" data-tags="seo">
  <div class="post-card__body">
    <span class="tag">Рубрика</span>
    <h4>Заголовок</h4>
    <p class="post-card__lead">Подводка на одно-два предложения.</p>
    <p class="post-meta">30 июля 2026 · 8 мин</p>
  </div>
</a>
```

Пока вместо фотографий стоят генерируемые заглушки: `<div class="visual visual--grid">`
внутри контейнера кадра. Меняются на `<img>` без правки стилей.

Рубрика задаётся атрибутом `data-tags` — по нему работает фильтр:
`keysy`, `kontekst`, `seo`, `razrabotka`, `analitika`. Можно указать несколько
через пробел.

## Что нужно заменить перед запуском

Разметка готова, содержание — нет. Демонстрационные данные помечены
комментарием `ДЕМО-ДАННЫЕ` в исходниках соответствующих страниц.

- **Цены и сроки** на страницах услуг — придуманы.
- **Метрики и цитаты в кейсах** («−42%», «×2,4», слова клиентов) — рыба.
- **Статьи журнала** — примеры заголовков, самих материалов нет.
  Кейсы лежат там же отдельной рубрикой: `zhurnal.html?rubrika=keysy`.
- **Фотографии** — вместо них градиентные плашки с подписью «заменить».
- **Карта** на странице контактов — заглушка под виджет Яндекс Карт.
- **Формы** ничего не отправляют: показывают сообщение об успехе и очищаются.
  Нужен обработчик на стороне сервера или интеграция с сервисом форм.

Реальные данные, взятые с действующего сайта: телефон, почта, адрес,
реквизиты ООО «ЦРВЕНА ЗВЕЗДА», регалии, имена основателей, логотипы клиентов.

Контакты в этом варианте — из логобука 2026 (`hello@redstaragency.ru`,
`+7 920 103 8130`). На действующем сайте они другие; какие верны, нужно уточнить.

## Индексация

Закрыта намеренно: `robots.txt` запрещает обход, на каждой странице стоит
`<meta name="robots" content="noindex, nofollow">`. Перед реальным запуском
это нужно снять.
